# PayPal Transaction Search API: PERMISSION_DENIED, No Permission for the requested operation

## Question

## Accepted answer

You need the scope `https://uri.paypal.com/services/reporting/search/read` .. if it's not there in the oauth2 response, double check your [REST App's permissions] and ensure that Transaction Search permission is enabled (box checked) there. If that was changed recently, see:

Refreshing an access token

Existing access tokens are cached for 9 hours--so if you've been using the API in the past 9 hours and more recently enabled the Transaction Search permission for your app, it can take up to 9 hours for that permission's new scope to be reflected in the next access_token's generation.

To avoid waiting 9 hours, you can terminate the current cached token with:

```
curl -X POST https://api-m.sandbox.paypal.com/v1/oauth2/token/terminate \
-u "yourclientid:yoursecret" \
-d "token=REPLACE_WITH_YOUR_TOKEN"

```

After termination, your next call to get a token will get a newly-generated one, including the new scope that was just added to the REST app.
