# SUP-1970: Mosaic Wholesale

## Customer report

Priority P2. The customer wrote: “reserved stock is duplicated when messages are replayed.” Their production environment used inventory-service 2.9 on Kubernetes with the standard Nexora dependency profile.

## Troubleshooting conversation

Support first confirmed scope, start time, affected tenants, and the exact upgrade window. The engineer requested request IDs and configuration values rather than secrets or full payloads. Healthy pods did not rule out downstream saturation. The engineer searched exact identifier INV-409 and then broadened the query using the customer's informal description.

## Diagnosis

The evidence matched INC-2025-011: replayed reservation messages used a non-stable operation key. Metrics and a controlled canary excluded unrelated gateway and authentication failures.

## Resolution

Support guided the customer through the approved containment and the permanent fix: deployed 2.9.1 with deterministic reservation idempotency keys. The customer verified representative operations, business counters, and fifteen minutes of normal error and latency levels.

## Related documentation

INC-2025-011; INV-409 in DOC-ERR-001; current inventory-service troubleshooting guide and release notes.
